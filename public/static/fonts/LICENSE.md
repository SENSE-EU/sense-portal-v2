# Font licences

The portal only bundles fonts that are free to use commercially. Fonts are
self-hosted so the portal never requests fonts.googleapis.com or
fonts.gstatic.com.

| Files                                          | Family | Copyright                                                                            | Licence                   |
| ---------------------------------------------- | ------ | ------------------------------------------------------------------------------------ | ------------------------- |
| `Outfit-latin.woff2`, `Outfit-latin-ext.woff2` | Outfit | Copyright 2021 The Outfit Project Authors (https://github.com/Outfitio/Outfit-Fonts) | SIL Open Font License 1.1 |

The WOFF2 files are the Google Fonts builds (variable weight 100–900, latin
and latin-ext subsets); the stylesheet uses weights 400–700. The full licence
text is in `OFL.txt`.

Other names in the font stacks (`-apple-system`, `Segoe UI`, `Helvetica`,
`Arial`, `Fira Code`, `Menlo` …) are only referenced as locally installed
fallbacks and are not shipped with the portal. Do not add font files here
unless their licence allows free commercial use and redistribution.
